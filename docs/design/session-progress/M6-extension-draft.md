# session-summary M6 扩展草案（未安装）

本文件是待合入原skill的附加能力规范，不是第二份可安装session-summary本体。

## 入口增量建议
当用户要求“按目标查看进度图”“跨会话任务DAG/看板/轨道”“一级二级三级任务上下钻”时，调用M6进度视图模式。M6复用M1–M3的材料与M5待办，不变更现有五模式产物和事实源。需要进度视图时才读详细规范；普通总结不加载图形规则。

## 执行步骤与完成条件
1. 定范围与输出位置：记录工作区、目标、窗口、source覆盖；沿原skill水位规范，不假定上次时间。完成条件：人能判断覆盖了哪些会话与哪些尚未读到。
2. 形成目标树：L1结果、L2交付、L3工作单元；同会话可拆段、同目标可跨会话。稳定ID优先，模糊匹配只进待归并。完成条件：每个节点有归属、验收目的与来源；未知明确标注。
3. 分关系与维度：parent归属、depends_on硬依赖、track推进线分开。M5状态、wait_reason、运行态、验收、freshness分别记录。完成条件：边有依据，父目标不因子项全完自动通过。
4. 主控复核：只接受当前版本适用证据，保留纠正链；新自报不自动销项。完成条件：每项当前状态有证据或“待核实”标记；关键问题附影响与下一动作。
5. 生成投影：确定性renderer从同snapshot生成视图；正式一期先B看板折叠树，DAG与多轨正式增强二期（本轮三稿仅参考）。首屏<=12主节点/4轨/3决策；超额显式入口。完成条件：焦点、计数、筛选、证据时间在三视图一致。
6. 安全交付：输出脱敏snapshot与内联数据HTML，不含原始聊天、密钥或登录态。按原skill命名与索引记录窗口，不覆盖旧报告。完成条件：离线打开、文本转义、无外链、上下钻和降级检查通过。

## 更新总控区
阶段边界由主控更新原有事实源，然后重建快照；worker仅返回receipt。总控区只展示当前目标/最近里程碑/待决定，以及snapshot版本、来源水位、生成时间、覆盖缺口。生成失败保留上次结果并标旧，不反写任务状态。

## 明确权限
M6是阅读投影，不创建Supervisor Task，不改变批准/验收，不写PTC或M5销项。若当前会话本就是主控，可先按相应控制skill登记事实；M6只消费登记后的状态。旁观monitor只提议变化，主控接受后才进入投影。
